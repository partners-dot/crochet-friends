# Videos Folder

This folder contains video assets for the landing page.

## Required Videos (Upload by User)

### Welcome Video
- `welcome.mp4` - Generic welcome video that plays on landing
  - Should show crocheted character saying "thank you for buying"
  - Mention the option to create personalized videos

### Buyer Examples (Greeting Card Style)
- `example-buyer-1.mp4` - Birthday greeting example
- `example-buyer-2.mp4` - Thank you message example  
- `example-buyer-3.mp4` - General greeting example

### Receiver Examples (Thank You Style)
- `example-receiver-1.mp4` - "Thank you for the gift" example
- `example-receiver-2.mp4` - "You're the best" example
- `example-receiver-3.mp4` - "I love it" example

## Video Specifications

- **Format**: MP4 (H.264)
- **Aspect Ratio**: 9:16 (vertical) or 1:1 (square) for mobile
- **Duration**: 5-15 seconds recommended
- **Size**: Keep under 10MB for fast loading
